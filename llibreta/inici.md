# ArquiLearn

La meva llibreta per aprendre programació a fons: patrons de disseny, principis, arquitectura i tot el que hi ha per sota del que faig servir cada dia.

## Com funciona

- **Llegir**: tria una pàgina del temari.
- **Editar**: prem **Editar** a dalt i obre la carpeta `llibreta` del repo (Chrome o Edge d'escriptori). Els canvis es desen al disc; després, commit i push, i GitHub Pages publica la versió nova.
- Cada carpeta és un **tema** i cada fitxer `.md` és una **pàgina**. Un número davant del nom (`01 Introducció`) serveix per ordenar i no es veu.

Comença per [Format i codi](00%20Llibreta/Format%20i%20codi.md) per veure què s'hi pot posar.
